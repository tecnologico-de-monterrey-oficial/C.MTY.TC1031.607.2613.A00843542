## Descripción

Este proyecto analiza registros de eventos de red utilizando diferentes estructuras de datos lineales implementadas en C++.

El programa permite cargar archivos de registros, ordenarlos por fecha y hora, realizar búsquedas por día, mostrar los resultados en orden descendente y obtener estadísticas.

## Estructuras utilizadas

- **LinkedList:** lista ligada simple utilizada como base para Queue y Stack.
- **Queue:** se utiliza como buffer para leer y procesar los registros respetando el orden de llegada.
- **DoublyLinkedList:** almacena los registros y permite recorrerlos y ordenarlos.
- **Stack:** permite mostrar los resultados de una búsqueda desde el registro más reciente hasta el más antiguo.

## Ordenamiento

Se utilizó **Merge Sort** adaptado a una lista doblemente ligada, con una complejidad esperada de O(n log n).
